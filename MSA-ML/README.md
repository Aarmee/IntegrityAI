# IntegrityAI – MSA & ML

This directory contains the Microservices Architecture and Machine Learning implementation of the IntegrityAI project.

## Microservices

1. Authentication Service
2. Faculty/Assignment Service
3. Submission Service
4. AI Analysis Service
5. Report Service
6. Notification Service

## Infrastructure

- Eureka Server
- API Gateway
- Apache Kafka
- Config Server

## Machine Learning

The AI Analysis Service performs assignment analysis and generates integrity-related analysis results.
