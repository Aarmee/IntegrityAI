# Config Server

## Purpose
Centralizes configuration properties for the IntegrityAI microservices.

## Main Responsibilities
- Store common configuration
- Provide configuration to microservices
- Avoid duplicating configuration across services
- Support centralized configuration management
- Make configuration changes easier to manage

## Technology
- Spring Boot
- Spring Cloud Config Server

## Managed Services

Configuration can be maintained for:

- Authentication Service
- Faculty Service
- Submission Service
- AI Analysis Service
- Report Service
- Notification Service
- API Gateway
- Eureka Server
